# md-book 0.1.0

The first cut is here. What's in it:

- **Core** — `renderMarkdown` with GFM, front matter, an extracted table of
  contents, `:::` containers, footnotes, and relative `.md` link rewriting.
- **Content model** — a `manifest.json` of your pages, route resolution, and
  auto nav / sidebar / prev-next.
- **Runtime** — `mount()` and `<md-book>`: client routing, an app shell, page
  caching with hover prefetch, code-copy buttons, and TOC scroll-spy. Plus a
  single-file `md-book.global.js` for `<script>` use.
- **Theming** — the `--md-book-*` token contract, an `@layer` stylesheet,
  light/dark, and a theme controller with a no-flash init script.
- **Blog** — dated posts, pagination, tag/category pages, and RSS / Atom / JSON
  feeds via `md-book feed`.
- **SEO** — canonical, Open Graph, Twitter, and Article JSON-LD on navigation.

Next up: a static-build mode and framework adapters.
