# アクセシビリティ

md-book は、標準の状態で WCAG 2.1 AA を満たすことを目指しています。

## 組み込み済みの対応

- ランドマーク構造: `<header>`、ラベル付きの `<nav>`、`<main>`、`<aside>`、`<footer>`、
  そして **本文へスキップ** するリンク。
- クライアント側のナビゲーションのたびにフォーカスが `<main>` に移り、ページの先頭（または
  `#hash` の位置）までスクロールします。
- サイドバーは現在のページを `aria-current="page"` で、目次は表示中の見出しを
  `aria-current="true"` で示します。
- テーマ切り替えは `aria-label` と `aria-pressed` を持つ本物の `<button>` です。
- `prefers-reduced-motion` ではトランジションを無効にします。
- 付属のテーマは、ライトでもダークでも AA のコントラストを満たします。

## 利用者側の責任

- Markdown の画像には、意味のある `alt` テキストを付けてください。
- 見出しのレベルは順に使ってください（`##` から `####` へ飛ばさないでください）。
- 独自のテーマを使う場合は、両方のモードでコントラストを確認し直してください。
- 生の HTML（`allowHtml`）を有効にした場合、そのアクセシビリティと安全性は利用者の責任です。

## テスト

ビルドしたページに [axe](https://github.com/dequelabs/axe-core) をかけ、サイトを Tab キーで
たどってください。操作できる要素にはすべて、見えるフォーカスリングが出るはずです
（md-book は `:focus-visible` を使います）。
