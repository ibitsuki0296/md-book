# 縦書き

ページの front matter に `writing: vertical` を書くと、本文が vertical-rl（縦書き）で組まれます。
行は上から下へ、列は右から左へ並び、ページは横にスクロールします。マウスホイールは横スクロールに割り当てられます。

```md
---
title: 短歌
writing: vertical
---

:::tanka
東海の小島の磯の白砂に
われ泣きぬれて
蟹とたはむる
:::
```

[実際の例](/ja/tanka)を見てください。

## `:::tanka` ブロック

`:::tanka` はソースの改行をそのまま保つので、ソースの 1 行が歌の 1 行になります。名前の後ろに
タイトルを書くと小さな見出しになります。横書きのページでも使えます。

:::tanka 一握の砂
たわむれに母を背負いて
そのあまり軽きに泣きて
三歩あゆまず
:::

## ルビ（ふりがな）

`{漢字|かんじ}` は `<ruby>`（`<rp>` 付き）でルビを表します。ルビ非対応の環境では 漢字(かんじ) と表示されます。
縦書き・横書きのどちらでも、見出しの中でも使えます。無効にするには render オプションで `ruby: false` を指定します。

:::tanka
{東海|とうかい}の{小島|こじま}の{磯|いそ}の{白砂|しろすな}に
われ{泣|な}きぬれて
{蟹|かに}とたはむる
:::

## 横書きページの中の縦書きブロック

1 つのブロックだけを縦書きにするには `:::vertical` を使うか、任意のコンテナに `.vertical` を付けます。

```md
:::tanka.vertical 一握の砂
ふるさとの訛なつかし
停車場の人ごみの中に
そを聴きにゆく
:::
```

:::tanka.vertical 一握の砂
ふるさとの訛なつかし
停車場の人ごみの中に
そを聴きにゆく
:::

:::vertical
どんな Markdown でも縦書きにできます。
数字は 12月3日 のように、二桁までなら縦中横になります。
:::

ブロックの高さは最大 `--md-book-vertical-height` で、はみ出すと横にスクロールします。
`writing: vertical` のページでは、すでに全体が縦書きなので `.vertical` は何も変えません。

## 調整

| トークン | 既定値 | 効果 |
|---|---|---|
| `--md-book-font-serif` | 明朝系スタック | 縦書きページと短歌の書体 |
| `--md-book-vertical-height` | `clamp(22rem, 72vh, 42rem)` | 縦書きの表示領域の高さ |

:::note
縦書きページの中でも、コードブロックと表は横書きのままです。
:::
