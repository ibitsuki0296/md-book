# md-book 0.1.0

最初の版ができました。内容は次のとおりです。

- **コア** — GFM、フロントマター、目次の抽出、`:::` コンテナ、脚注、相対 `.md` リンクの書き換えに
  対応した `renderMarkdown`。
- **コンテンツモデル** — ページの `manifest.json`、ルート解決、ナビ／サイドバー／前後ページの自動生成。
- **ランタイム** — `mount()` と `<md-book>`。クライアントルーティング、アプリシェル、ホバーで先読みする
  ページキャッシュ、コードのコピーボタン、目次のスクロールスパイ。`<script>` で使える単一ファイルの
  `md-book.global.js` も付きます。
- **テーマ** — `--md-book-*` トークンの規約、`@layer` のスタイルシート、ライト／ダーク、ちらつきを防ぐ
  初期化スクリプト付きのテーマコントローラ。
- **ブログ** — 日付付きの記事、ページネーション、タグ／カテゴリのページ、`md-book feed` による
  RSS / Atom / JSON フィード。
- **SEO** — ページ遷移時に canonical、Open Graph、Twitter、Article の JSON-LD を反映。

次は、静的ビルドモードとフレームワークアダプタです。
